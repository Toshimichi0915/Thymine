# Thymine

Thymine fixes small bugs and improves combat experience

This mod supports Minecraft 1.16, 1.17, 1.18, 1.19, and requires fabric loader and fabric api

![2021-08-21_00 49 23](https://user-images.githubusercontent.com/26406334/130259883-ef019291-5a2e-447e-a198-d88d80dc1162.png)

### Features

1. FastSneak - Removes sneak animation
2. FullBright - Gives night vision effect
3. ToggleSprint - Allows you to toggle sprint
4. LowFire - Decreases fire height
5. SoftSneak - Increases sneak height
6. ForceIcon - Always shows your potion effects on your screen
7. AntiSwim - Disables swimming pose for servers using ViaVersion
8. PotionHUD - Shows potion HUD
9. ArmorHUD - Shows armor HUD
10. NoStatusOverlay - Hides default status overlay
11. NoScreenBobbing - Prevents screen bobbing but does not prevent hand bobbing
12. ShowHitBox - Shows entity hitboxes
